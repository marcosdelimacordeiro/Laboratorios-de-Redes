# Documentação Técnica – Laboratório 01

## Objetivo

Apresentar os procedimentos realizados durante a instalação e configuração do ambiente virtualizado para estudos de Redes de Computadores utilizando VMware, EVE-NG e MikroTik CHR.

## Relatório técnico

O documento apresenta as atividades desenvolvidas durante o laboratório, incluindo configurações iniciais, procedimentos técnicos e ferramentas utilizadas.

- [Acessar relatório técnico em PDF](./laboratorio-01-configuracao-basica-mikrotik.pdf)

## Conteúdo abordado

- Virtualização com VMware.
- Instalação e configuração do EVE-NG.
- Configuração inicial do MikroTik CHR.
- Identificação de interfaces de rede.
- Endereçamento IP e roteamento.
- Gerenciamento de usuários.
- Configuração de data, hora e NTP.
- Backup e exportação de configurações.
- Agendamento de tarefas.

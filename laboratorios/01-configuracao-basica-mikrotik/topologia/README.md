# Topologia de Rede – Laboratório 01

## Objetivo

Documentar a topologia de rede desenvolvida no EVE-NG para a prática de configurações básicas do MikroTik CHR.

## Equipamentos utilizados

| Equipamento | Função |
|---|---|
| Cloud (Internet) | Representação da rede externa (WAN) |
| MikroTik CHR | Roteador e gerenciamento da rede |
| Linux | Dispositivo cliente da rede local (LAN) |

## Estrutura da topologia

```text
Internet (WAN)
      |
    ether1
 MikroTik CHR
    ether2
      |
     Linux
```


## Arquivo do laboratório

O arquivo ZIP disponibilizado neste diretório contém a topologia exportada do EVE-NG.

- [Baixar Laboratório 01 – EVE-NG](./laboratorio-01-eve-ng.zip)


## Como utilizar

1. Baixar o arquivo ZIP do laboratório.
2. Acessar a interface web do EVE-NG.
3. Importar o arquivo do laboratório.
4. Verificar a disponibilidade das imagens dos equipamentos.
5. Abrir o laboratório e iniciar os dispositivos.
6. Realizar as configurações e os testes de conectividade.

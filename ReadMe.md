# Laboratórios de Redes de Computadores

## Sobre o repositório

Este repositório tem como objetivo documentar meus estudos e atividades práticas em Redes de Computadores e Infraestrutura de TI.

Os laboratórios são desenvolvidos em ambientes virtualizados, aplicando conhecimentos de configuração, administração e diagnóstico de redes.
